    Which meetings open

    An event opens if all of these apply:

    • It's on the primary calendar of a connected account. Other calendars, including ones you follow, aren't checked.
    • It has a Google Meet, Zoom or Microsoft Teams link: as its video call, or in its location or description, checked in this order. Only the first link found opens.
    • It starts at a set time. All-day events don't open.
    • It isn't cancelled, and isn't an out-of-office, focus time, working location or birthday event.
